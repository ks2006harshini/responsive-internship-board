# 💜 InternBoard – Responsive Internship Board

## 📌 Project Overview

InternBoard is a responsive internship listing website designed to help students discover and apply for internship opportunities.

The website allows students to search for internships, filter opportunities based on domain and work mode, view internship details, and submit applications.

The project is developed using HTML, CSS, and JavaScript without using any frontend framework.

## 🎯 Objectives

- Build a responsive internship listing website.
- Provide search functionality for internship opportunities.
- Filter internships based on domain and work mode.
- Display internship details.
- Allow students to submit internship applications.
- Create an accessible and user-friendly interface.

## ✨ Features

1. **Home Page**
   - Modern and attractive landing page.
   - Lavender and pink colour theme.
   - Internship search bar.

2. **Internship Listings**
   - Display available internship opportunities.
   - Show internship title, domain, location and openings.
   - Display required skills.

3. **Search Functionality**
   - Search internships by title.
   - Search by skills and location.

4. **Domain Filter**
   - Full Stack Development
   - UI/UX
   - Data Analytics
   - Cyber Security

5. **Work Mode Filter**
   - Remote
   - Hybrid
   - On-site

6. **View Details**
   - View complete internship information.

7. **Apply Now**
   - Enter applicant name.
   - Enter email address.
   - Provide an optional portfolio URL.
   - Submit an internship application.

8. **Responsive Design**
   - Mobile-friendly layout.
   - Tablet-friendly layout.
   - Desktop-friendly layout.

9. **User Experience**
   - Loading state.
   - Error state.
   - Empty search results.
   - Retry option.

## 💻 Installation and Setup

### Step 1: Install Node.js

Download and install Node.js from:

https://nodejs.org/

### Step 2: Open the Project

Open the InternshipBoard folder in Visual Studio Code.

### Step 3: Open the Terminal

Use the following command to start the backend server:

```bash
node server.js
```

### Step 4: Run the Website

Open the following URL in your browser:

```text
http://localhost:3000
```
